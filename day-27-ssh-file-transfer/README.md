# Day 27 — Remote Access & File Transfer

## Overview

Day 27 covers SSH remote access, key management, secure file
transfer, synchronization, and SSH client configuration.

## Topics Covered

- SSH connections
- Custom SSH ports
- Identity files
- SSH key generation
- Public-key installation
- SCP and SFTP
- Rsync
- SSH client configuration
- Secure file permissions and host verification

## Practical Exercise

I inspected SSH tools, practiced key generation and configuration,
created a test file, and used rsync for a local transfer exercise.

Remote transfer exercises require an authorized server and should
only be marked complete after a successful connection or transfer.

## Key Takeaway

Secure remote access depends on careful key management,
host verification, permissions, and appropriate file-transfer tools.
