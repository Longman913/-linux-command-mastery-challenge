# Day 27 — Remote Access & File Transfer

## Commands Practiced

1. `ssh` — Connect to a remote host securely.
2. `ssh -p` — Connect using a specified port.
3. `ssh -i` — Select an identity file.
4. `ssh-keygen` — Generate SSH keys.
5. `ssh-copy-id` — Install a public key on an authorized remote account.
6. `scp` — Copy files securely over SSH.
7. `sftp` — Transfer files through an interactive SSH session.
8. `rsync` — Synchronize files and directories.
9. `~/.ssh/config` — Store per-host SSH client settings.
10. SSH hardening — Apply secure key permissions and client configuration.

## Key Learning

SSH provides secure remote access, while SCP, SFTP, and rsync
support secure file transfer and synchronization.
