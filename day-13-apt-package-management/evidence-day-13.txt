=== DAY 13 — APT PACKAGE MANAGEMENT ===

1. Refresh package index
Command: sudo apt update

2. Search for a small utility
Command: apt search tree

3. Install utility
Command: sudo apt install tree -y

4. Inspect package details
Command: apt show tree

5. List files installed by package
Command: dpkg -L tree

6. Purge package and configuration files
Command: sudo apt purge tree -y

7. Remove unused dependencies
Command: sudo apt autoremove -y

8. Verify package removal
Command: dpkg -l tree

Result: tree package was successfully removed and is no longer installed.
