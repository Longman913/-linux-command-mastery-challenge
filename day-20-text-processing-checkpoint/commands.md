# Day 20 — Text Processing & Pipes

## Commands Practiced

1. `grep`
   - Searches for matching text.

2. `grep -r`
   - Searches recursively through directories.

3. `grep -i`
   - Performs a case-insensitive search.

4. `sort`
   - Sorts lines alphabetically.

5. `sort -n`
   - Sorts numeric values.

6. `uniq`
   - Removes adjacent duplicate lines.

7. `cut -d':' -f`
   - Extracts selected fields using a delimiter.

8. `awk '{print $1}'`
   - Extracts and processes the first field.

9. `sed 's/old/new/g'`
   - Replaces text within input.

10. `|`
    - Pipes the output of one command into another command.

## Key Learning

Linux text-processing commands can be combined with pipes to build
powerful command-line data-processing workflows.
