# Day 30 — Capstone Commands

1. `ps` — Inspect running processes.
2. `systemctl` — Inspect and manage systemd services when supported.
3. `journalctl` — Inspect system journal entries when available.
4. `ssh` — Execute commands on an authorized remote host.
5. `scp` — Copy files securely over SSH.
6. `chmod` — Change file permissions.
7. `chown` — Change file ownership when authorized.
8. `grep` — Filter text by pattern.
9. `awk` — Extract and process fields.
10. `sed` — Transform text.
11. `find` — Locate files by criteria.
12. `cron` and `crontab` — Schedule recurring tasks.
13. `who` — Display logged-in users.
14. `last` — Inspect login-accounting records when available.
15. `history` — Review commands recorded by the shell.

## Key Learning

A reliable administrative workflow combines system inspection,
automation, secure file handling, log analysis, and verification.
