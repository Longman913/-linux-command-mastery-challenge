# Day 30 — Capstone: Full System Command Mastery Review

## Overview

The final day combines Linux administration, Bash scripting,
system monitoring, file permissions, networking, log processing,
and basic security auditing.

## Activities

- Built a Bash health-check script.
- Collected hostname, kernel, disk, memory, network, and process information.
- Checked whether systemd and journal access were available.
- Practised SSH and SCP command syntax.
- Applied and verified permissions on a test deployment file.
- Processed sample logs using grep, awk, and sed.
- Located files using find.
- Reviewed user identity and login-history commands.
- Checked cron availability.

## Practical Result

The health-check script generates a timestamped report.
Remote deployment and service-management tasks depend on
an authorized server and the available system configuration.

## Key Takeaway

The capstone brings together Linux commands into a repeatable
workflow for monitoring, troubleshooting, and automation.
