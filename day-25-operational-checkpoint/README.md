# Day 25 — Process & Service Checkpoint

## Overview

This checkpoint combines Linux process management, service
inspection, logging, and system resource monitoring.

## Topics Covered

- Process identification
- Service status
- Service logs
- Process existence checks
- System uptime and load
- Memory and swap usage
- Virtual memory statistics
- Disk I/O statistics
- Repeated monitoring
- Interactive process monitoring

## Practical Exercise

The exercise involved building a basic operational report,
checking a service and its logs, inspecting memory and process
activity, and monitoring system resources.

## Key Takeaway

A structured operational check helps identify possible service
problems and resource pressure before deeper troubleshooting.
