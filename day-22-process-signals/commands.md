# Day 22 — Controlling Processes With Signals

## Commands Practiced

1. `kill` — Send a signal to a process.
2. `kill -9` — Forcefully terminate a process.
3. `kill -HUP` — Send the hangup signal.
4. `killall` — Send a signal to processes by name.
5. `pkill` — Select and signal processes by name or pattern.
6. `fg` — Bring a background job to the foreground.
7. `bg` — Resume a stopped job in the background.
8. `Ctrl+Z` — Suspend the foreground process.
9. `nohup` — Run a command so it can continue after logout.
10. `disown` — Remove a job from the shell's job table.

## Key Learning

Linux signals provide a mechanism for controlling running processes,
while shell job-control commands manage foreground and background
processes.
