# Day 22 — Controlling Processes With Signals

## Overview

Day 22 focused on controlling Linux processes using signals and
foreground/background job management.

## Topics Covered

- Process termination
- Process signals
- Forced termination
- Job suspension
- Background jobs
- Foreground jobs
- nohup
- disown

## Practical Exercise

A long-running command was started, suspended with Ctrl+Z, resumed
in the background, brought back to the foreground, and terminated.
A second command was started with nohup so it could continue beyond
the current terminal session.

## Key Takeaway

Understanding signals and job control is important when managing
long-running tasks and troubleshooting processes on Linux systems.
