# Day 21 — Viewing Processes

## Commands Practiced

1. `ps aux` — Display all running processes.
2. `ps -ef` — Display processes in full format.
3. `ps -u` — Display processes for a specific user.
4. `top` — Monitor processes in real time.
5. `htop` — Interactive process monitor. Installation was attempted but failed because of an Ubuntu repository error.
6. `pgrep` — Find process IDs by process name.
7. `pstree` — Display processes in a hierarchical tree.
8. `lsof -i` — Display processes using network connections.
9. `jobs` — Display jobs managed by the current shell.
10. `nice / renice` — Start a process with a modified priority and change its priority.

## Key Learning

Linux provides several commands for viewing, identifying, monitoring,
and managing running processes.
