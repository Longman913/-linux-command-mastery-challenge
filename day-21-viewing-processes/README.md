# Day 21 — Viewing Processes

## Overview

Day 21 focused on viewing, identifying, monitoring, and inspecting
Linux processes.

## Topics Covered

- Process listing
- Process identification
- Real-time process monitoring
- Process hierarchy
- Network process inspection
- Shell jobs
- Process priority

## Practical Exercise

I identified running processes by name, inspected their PIDs,
viewed the process hierarchy, checked network processes and port 80,
managed background jobs, and practiced changing process priority
with `nice` and `renice`.

## Note

The installation of `htop` was attempted but could not be completed
because the Ubuntu package repository returned a remote/cache error.
The `top` command was successfully used for process monitoring.

## Key Takeaway

Understanding Linux processes is essential for system monitoring,
troubleshooting, performance analysis, and administration.
