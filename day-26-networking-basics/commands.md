# Day 26 — Networking Basics

## Commands Practiced

1. `ip a` — Display network interfaces and addresses.
2. `ip route` — Display the routing table.
3. `ping -c` — Send a specified number of connectivity probes.
4. `curl` — Transfer data to or from a URL.
5. `curl -I` — Request HTTP response headers.
6. `wget` — Download files from the web.
7. `netstat -tulnp` — Display listening TCP/UDP sockets and available process information.
8. `ss -tulnp` — Inspect listening sockets and available process information.
9. `hostname` — Display the system hostname.
10. `hostnamectl` — Display hostname and system identity information when supported.

## Key Learning

Linux networking commands help inspect interfaces, routing,
connectivity, HTTP responses, and listening ports.
