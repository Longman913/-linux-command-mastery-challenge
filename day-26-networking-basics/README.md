# Day 26 — Networking Basics

## Overview

Day 26 introduces Linux networking commands for inspecting
interfaces, routes, connectivity, and listening ports.

## Topics Covered

- Network interfaces and IP addresses
- Routing tables and default gateways
- Connectivity testing
- HTTP requests and headers
- File downloads
- TCP and UDP listening sockets
- Hostname identification

## Practical Exercise

I inspected network interfaces and routes, tested connectivity,
retrieved HTTP headers, attempted a file download, and checked
listening ports.

## Key Takeaway

Understanding basic networking commands is essential for
troubleshooting connectivity and inspecting services running
on a Linux system.
