# Day 18 — Vim Fundamentals

## Commands and Actions Practiced

1. `vim <file>`
   - Opens or creates a file using Vim.

2. `i`
   - Enters Insert Mode for typing and editing text.

3. `Esc`
   - Returns to Normal/Command Mode.

4. `:w`
   - Saves the current file.

5. `:q`
   - Quits Vim.

6. `:wq`
   - Saves the file and quits Vim.

7. `:x`
   - Saves changes and exits Vim.

8. `:q!`
   - Quits Vim without saving changes.

9. `dd`
   - Deletes the current line.

10. `yy / p`
    - Copies the current line and pastes it.

11. `u`
    - Undoes the most recent change.

12. `Ctrl+r`
    - Redoes an undone change.
