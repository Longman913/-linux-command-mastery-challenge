# Day 18 — Vim Fundamentals

## Overview

Day 18 focused on the fundamentals of Vim, a powerful terminal-based
text editor commonly available on Linux systems.

## Topics Covered

- Opening files with Vim
- Insert Mode
- Normal Mode
- Saving files
- Exiting Vim
- Deleting lines
- Copying and pasting
- Undo and redo

## Practical Exercise

A file named `practice.txt` was created using Vim. Three lines of text
were entered and saved. The file was then reopened, the middle line was
deleted, the deletion was undone, and redo was tested.

The final version was saved and verified from the terminal.

## Key Takeaway

Vim's modal editing system makes it possible to separate text entry
from file-editing commands, making the terminal editor efficient once
the basic commands are familiar.
