# Day 18 — Practice Drill

## Objective

Practice the basic Vim workflow by creating, editing, saving, reopening,
deleting, undoing, redoing, and saving a text file.

## Actions Completed

### 1. Created a file

Opened a new file with:

`vim practice.txt`

### 2. Entered Insert Mode

Pressed:

`i`

### 3. Added three lines

The following text was entered:

Linux Command Mastery
Learning Vim Fundamentals
Day 18 Practice

### 4. Saved the file

Pressed `Esc` and used:

`:w`

### 5. Exited Vim

Used:

`:q`

### 6. Reopened the file

Used:

`vim practice.txt`

### 7. Deleted the middle line

Used:

`dd`

### 8. Undid the deletion

Used:

`u`

### 9. Tested redo

Used:

`Ctrl+r`

### 10. Restored the line

Used:

`u`

### 11. Saved and exited

Used:

`:wq`

### 12. Verified the final file

Used:

`cat practice.txt`

## Key Learning

Vim uses different modes for editing and commands. Insert Mode is used
for entering text, while Normal Mode allows commands such as deleting,
copying, undoing, saving, and exiting.
