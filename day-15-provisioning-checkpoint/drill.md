# Day 15 Practice Drill

## Objective

Provision a complete new team member account with a user, group, password, and the tools required for the role.

## Tasks Completed

- Created the `devteam` group.
- Created the `teamuser` account.
- Created a home directory for `teamuser`.
- Assigned `/bin/bash` as the user's shell.
- Added `teamuser` to the `devteam` group.
- Set a password for `teamuser`.
- Verified the user's identity and group membership.
- Checked installed packages.
- Checked available package upgrades.
- Updated the APT package information.
- Verified the required tools: `tree`, `curl`, and `vim`.
