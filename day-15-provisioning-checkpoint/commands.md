# Day 15 — Users & Packages Checkpoint

## Commands Practiced

1. `id <user>` — Displays user ID, group ID, and group membership.
2. `getent passwd <user>` — Displays account information from the passwd database.
3. `useradd -m -G` — Creates a user with a home directory and adds them to a group.
4. `passwd <user>` — Sets or changes a user's password.
5. `apt list --installed` — Lists installed packages.
6. `apt list --upgradable` — Lists packages that can be upgraded.
7. `apt update` — Updates the package repository information.
8. `dpkg -l | grep` — Searches installed packages.
9. `apt autoremove` — Removes packages that are no longer required.
10. `history` — Displays previously executed commands.
