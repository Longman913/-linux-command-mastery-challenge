# Day 19 — Practice Drill

## Objective

Work with a 50-line configuration file and practice Vim navigation,
search, search navigation, and global text replacement.

## Actions Completed

1. Created a 50-line configuration file named `config.txt`.
2. Opened the file with Vim.
3. Used `gg` to move to the beginning.
4. Used `G` to move to the end.
5. Used `:10` to jump directly to line 10.
6. Used `/server` to search forward.
7. Used `n` to move to the next search match.
8. Used `N` to move to the previous match.
9. Used `?server` to search backward.
10. Practiced `dw` to delete a word.
11. Practiced `x` to delete a character.
12. Practiced `o` and `O` to open new lines.
13. Used `zz` to center the current line.
14. Used `:%s/server/node/g` to replace every occurrence of `server` with `node`.
15. Saved and exited Vim.
16. Verified the final file from the terminal.

## Key Learning

Vim search and navigation commands make it possible to quickly locate
and modify specific content in large configuration files.
