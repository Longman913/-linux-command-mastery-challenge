# Day 19 — Vim Navigation & Search/Replace

## Overview

Day 19 focused on navigating and modifying files efficiently with Vim.

## Topics Covered

- File navigation
- Line jumping
- Forward and backward search
- Search result navigation
- Word deletion
- Character deletion
- Opening new lines
- Screen positioning
- Global search and replace

## Practical Exercise

A 50-line configuration file was created and opened in Vim. I practiced
jumping to line 10, searching for keywords, navigating between matches,
and replacing every occurrence of a word throughout the file.

## Key Takeaway

Vim provides efficient tools for navigating and making large-scale text
changes directly from the Linux terminal.
