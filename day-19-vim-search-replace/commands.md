# Day 19 — Vim Navigation & Search/Replace

## Commands Practiced

1. `gg / G`
   - Move to the beginning or end of the file.

2. `:10`
   - Jump directly to line 10.

3. `/`
   - Search forward.

4. `?`
   - Search backward.

5. `n / N`
   - Move to the next or previous search match.

6. `:%s/old/new/g`
   - Replace every occurrence of a word throughout the file.

7. `dw`
   - Delete a word.

8. `x`
   - Delete a character.

9. `o / O`
   - Open a new line below or above the current line.

10. `zz`
    - Center the current line on the screen.

## Key Learning

Vim provides powerful navigation and search tools that allow users
to quickly move through and modify large text files from the terminal.
