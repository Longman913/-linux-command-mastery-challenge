# Day 1 Practice Drill

## Task

Navigate through the Linux filesystem by checking my current location, moving to /var/log, returning to my home directory, returning to /var/log, and displaying the directory contents.

## Commands I ran

pwd
cd /var/log
cd ~
cd -
ls -lh

## Result

I successfully navigated to /var/log, returned to my home directory using ~, returned to /var/log using cd -, and displayed the contents of the directory using ls -lh.
