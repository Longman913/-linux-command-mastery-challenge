# Day 1: File Navigation Commands

## 1. pwd
Shows the full path of the directory I am currently working in.

## 2. ls
Displays the files and folders in the current directory.

## 3. ls -l
Displays directory contents with detailed information such as permissions, ownership, size, and modification time.

## 4. ls -a
Shows all files and folders, including hidden files.

## 5. ls -la
Combines the detailed listing with hidden files.

## 6. ls -lh
Shows detailed file information while displaying file sizes in an easier-to-read format.

## 7. cd /path
Moves from the current directory to a specific directory using its full path.

## 8. cd ..
Moves to the parent directory of the current location.

## 9. cd ~
Takes me directly to my home directory.

## 10. cd -
Returns me to the previous directory I was working in.
