# Day 1: Where Am I? Basic Orientation

## Phase 1 - File Navigation & Filesystem Mastery

Today I practiced the basic Linux commands used to understand my location and move around the filesystem.

## Commands Covered

I practiced pwd, ls, ls -l, ls -a, ls -la, ls -lh, cd, cd .., cd ~, and cd -.

## What I Practiced

I navigated from my home directory to /var/log, returned to my home directory, then used cd - to return to /var/log. I also used ls -lh to inspect the contents of the log directory.

## What Surprised Me

I learned that cd - can quickly return me to the previous directory, while ~ provides a shortcut to my home directory.
