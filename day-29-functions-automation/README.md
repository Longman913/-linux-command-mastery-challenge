# Day 29 — Functions, Arguments & Automation

## Overview

Day 29 focuses on reusable Bash functions, command-line arguments,
exit codes, logging, and scheduled automation.

## Topics Covered

- Function definitions
- Positional arguments
- Argument counts and lists
- Script names and exit codes
- Cron scheduling
- Background execution with nohup
- Signal and exit handling with trap
- Logging with logger
- Service-status checks

## Practical Exercise

I created reusable functions, tested command-line arguments and
exit statuses, practised logging and background execution, and
built a service-check script with error handling.

## Key Takeaway

Well-designed automation scripts should be reusable, predictable,
and able to report failures clearly.
