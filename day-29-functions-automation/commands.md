# Day 29 — Functions, Arguments & Automation

## Commands and Concepts Practiced

1. `function_name() { ... }` — Define reusable Bash functions.
2. `$1` / `$2` — Access positional arguments.
3. `$#` / `$*` / `$@` — Inspect and process arguments.
4. `$0` — Reference the script name.
5. `$?` — Read the last command's exit status.
6. `crontab -e` — Edit the user's cron schedule.
7. Cron expressions — Define scheduled execution times.
8. `nohup` — Run commands that can survive terminal logout.
9. `trap` — Handle exit or signal events.
10. `logger` — Send messages to the logging facility.

## Key Learning

Functions, arguments, exit codes, and automation tools make Bash
scripts more reusable, observable, and maintainable.
