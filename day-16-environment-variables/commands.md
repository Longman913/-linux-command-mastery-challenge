# Day 16 — Environment Variables

## Commands Practiced

1. `printenv` — Displays environment variables.
2. `printenv HOME` — Displays the HOME environment variable.
3. `echo $VAR` — Displays the value of a variable.
4. `export` — Creates or exports an environment variable.
5. `unset` — Removes an environment variable.
6. `env` — Displays the current environment.
7. `source` — Reloads a shell configuration file.
8. `echo $PATH` — Displays the current PATH.
9. `export PATH=$PATH:...` — Adds a directory to PATH for the current session.
10. `cat /etc/environment` — Displays system-wide environment configuration.
