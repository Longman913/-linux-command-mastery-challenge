# Day 16 Practice Drill

## Objective

Practice creating, checking, removing, and modifying environment variables and PATH settings.

## Tasks Completed

- Checked the current environment using `printenv`.
- Checked the `HOME` environment variable.
- Created a temporary `DAY16` environment variable.
- Verified the variable using `echo` and `env`.
- Removed the variable using `unset`.
- Confirmed that the variable was removed.
- Checked the current `PATH`.
- Created a personal `day16-bin` directory.
- Created an executable test script.
- Added the directory to PATH for the current shell session.
- Used `which` to confirm that the shell could locate the script.
- Executed the script using its command name.
- Checked environment variables again.
- Inspected `/etc/environment`.
