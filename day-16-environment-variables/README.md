# Day 16 — Environment Variables

## Overview

Day 16 focused on understanding and managing environment variables in Linux.

I practiced viewing existing environment variables, creating temporary variables, removing variables, and working with the PATH environment variable.

## Practical Work

I created a temporary `DAY16` variable and verified it using `echo` and `env`. I then removed it with `unset` and confirmed that it was no longer available.

I also created a directory containing a small executable script and added that directory to the PATH for the current shell session. I verified the configuration using `which` and successfully executed the script without specifying its full path.

## Key Takeaway

Environment variables are an important part of Linux because they influence how applications and commands behave. Understanding PATH in particular makes it easier to manage custom scripts and command-line tools.
