# Day 17 — Persisting Configuration

## Commands Practiced

1. `nano ~/.bashrc`
   - Opens the user's Bash configuration file for editing.

2. `source ~/.bashrc`
   - Reloads the Bash configuration in the current shell.

3. `cat ~/.bash_profile`
   - Displays the user's Bash login profile.

4. `sudo nano /etc/environment`
   - Opens the system-wide environment configuration file.

5. `sudo nano /etc/bash.bashrc`
   - Opens the system-wide Bash configuration file.

6. `alias`
   - Displays configured shell aliases.

7. `unalias`
   - Removes an alias from the current shell session.

8. `type`
   - Shows how Bash interprets a command.

9. `which`
   - Shows the path of an executable command.

10. `whereis`
    - Locates the binary, source, and manual-page files associated with a command.

## Key Learning

Shell configuration files such as `.bashrc` allow environment variables and aliases to persist across Bash sessions.
