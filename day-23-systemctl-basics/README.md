# Day 23 — Init Systems & systemctl Basics

## Overview

Day 23 focused on Linux service management using systemctl
and the systemd init system.

## Topics Covered

- Starting services
- Stopping services
- Restarting services
- Reloading service configurations
- Enabling services
- Disabling services
- Checking service activity
- Checking service enablement
- Viewing service status

## Practical Exercise

I used the cron service to practice stopping and restarting
a service, confirming its active state, enabling it for
automatic startup, and verifying its configuration.

I also practiced using `systemctl enable --now` to enable
and start a service in a single command.

## Key Takeaway

Understanding systemctl is important for Linux system
administration because it provides a standard way to manage
services and control how they behave during system startup.
